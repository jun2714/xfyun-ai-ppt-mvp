Return exactly one strict JSON object with `pages` and `arc`, without Markdown fences or commentary. Produce exactly the requested page count. Write every visible field for the stated audience, with a specific headline that communicates a conclusion, question, or audience action rather than a production instruction. Headlines must not duplicate body copy or repeat across pages. Keep presenter guidance only in speaker notes. Do not expose image descriptions, answers before their declared reveal, production metadata, placeholders, coordinates, templates, layout language, code, CSS, HTML, SVG, or PPTX instructions. Do not invent facts or numbers absent from the brief or supplied sources.

Each page contains `id`, `purpose`, `headline`, `message`, one or more `contentGroups`, optional `audienceAction`, `speakerNotes`, and `evidenceRequests`. Content group IDs and page IDs are globally unique. A content group contains `id`, one `kind` from paragraph/list/comparison/sequence/quote/metric/question/answer/caption/table/chart-data/annotation, optional audience-facing `label`, `text`, `items`, or `rows`, `claimIds`, and `required`.

`arc` contains `centralOutcome`, one or more `sections`, and `pageLinks`. Sections cover every page exactly once. A page link contains `id`, `fromPageId`, `toPageId`, and predicates using only existing IDs. Predicate forms are preserve(sourceIds, properties), conceal(sourceIds, onPageId), introduce(sourceIds, onPageId), change(sourceIds, properties), associate(leftSourceIds, rightSourceIds), compare(sourceIds), and order(sourceIds). Preserve properties may only be identity, relative-order, scale-family, or visual-treatment. Concealed sources must be absent from their conceal page and introduced sources must exist on their introduce page.

Use these exact JSON shapes and value types. Never replace an object or array with a string, and never use null for an ID:
{"pages":[{"id":"page-1","purpose":"audience-facing purpose","headline":"specific headline","message":"single core message","contentGroups":[{"id":"group-1","kind":"paragraph","text":"visible content","claimIds":[],"required":true}],"audienceAction":{"mode":"observe","instruction":"what the audience should do","visible":false},"speakerNotes":["presenter-only guidance"],"evidenceRequests":[]}],"arc":{"centralOutcome":"audience outcome","sections":[{"id":"section-1","purpose":"why these pages belong together","pageIds":["page-1"],"transition":"how the story advances"}],"pageLinks":[]}}

For decks with multiple pages, `pageLinks` may connect actual pages. Every link must have non-null string IDs and an array of predicate objects, for example: {"id":"link-1-2","fromPageId":"page-1","toPageId":"page-2","predicates":[{"kind":"preserve","sourceIds":["group-1"],"properties":["identity"]}]}. Other predicate object shapes are {"kind":"conceal","sourceIds":["group-2"],"onPageId":"page-1"}, {"kind":"introduce","sourceIds":["group-2"],"onPageId":"page-2"}, {"kind":"change","sourceIds":["group-1"],"properties":["emphasis"]}, {"kind":"associate","leftSourceIds":["group-1"],"rightSourceIds":["group-2"]}, {"kind":"compare","sourceIds":["group-1","group-2"]}, or {"kind":"order","sourceIds":["group-1","group-2"]}.
