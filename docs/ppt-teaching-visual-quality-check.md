# 教学配图与互动质量：2026-11-17 Windows 实测

本次基于 `fix/kindergarten-generation-stability` 的 `2ac32b5` 修复。目标是认知观察页使用准确 AI 写实图，独立互动页使用卡通图，每张图支持本页的具体教学动作。

## 截图问题的代码原因

- 原有课堂映射和最终图片请求都强制儿童绘本，写实要求不能可靠传到供应商。
- 实际第 8 页三张卡分别标注鱼、蟹、章鱼，三段画面描述却完全相同，均要求三种动物在舞台合影。供应商按这段提示生成，仍然会得到不对应的图。
- 第 7 页标记为配对任务，却已经在每张卡写出正确动物与动作；“找回家的路”没有道路、目的地或分开的待配选项。真实可执行的活动其实是教师发口令、幼儿模仿。
- 早上的内容审核是显式启动的文本审核，不是每次生成后的图片像素验收。供应商恢复出图不能解决上述问题。

## 修改

1. 逐页传递 `visual_representation`，支持 `realistic`、`illustration` 和兼容旧稿的 `auto`。科学/健康认知观察页默认自然写实；独立活动、故事和教研使用相应插画。模板映射、AI 背景、素材分组及最终供应商请求共用此规则，不跨画风复用图片。写实图始终是 AI 图，不能称为实拍。
2. 图文卡只携带自身的对象与动作。不同语义对象复用完全相同的画面描述会在付费生成前被拦截。保留同一个对象的有意重复，例如数苹果。
3. 生成要求核对标题、可见线索、幼儿动作和反馈。真正的配对必须分开候选项；模仿不再标成“做出选择”，新增动作模仿、配对与分类活动标记。规则禁止把静态图当成可播放的连续运动。
4. 已直接展示全部对应答案的配对页作为内容错误处理。重复卡片画面也是内容错误，不能靠删除游戏或图片契约绕过。
5. 审核接受可唯一定位的数组原文证据；只有同时明确“不构成问题”和“无需修改”的确认记录才从缺陷列表移除，真正矛盾的意见仍拒绝。修订保留原知识/观察页类型；每个修改页必须改变至少一处引用的原文，其他意见是否解决仍由独立复审确认。游戏身份、必要图片和未定位页面继续受保护。
6. 新增字段不破坏之前保存的审核源：先校验原始快照摘要，再补模型默认值。旧快照仍可以重新审核与采用，过期稿不能覆盖手动修改。
7. 用户指出首版写实鱼可能与海洋环境不符后，撤销了该样张的认知验收。新增 `observation_subjects`，明确写实认知图的具体对象、真实环境和可见识别特征；缺失身份或仅写“银色海鱼”等泛称会拦截。身份要求传到图片供应商、素材复用与可选视觉检查；互动卡沿用同一物种。填写这些信息仍不等于事实或图片已被独立核实。

## 实测结果

| 检查 | 结果与范围 |
| --- | --- |
| Python 3.11 / Windows 回归 | 459 项通过，覆盖课堂映射、模板、素材规划与执行、内容审核、真实 SQLite 路由及并发保存保护；不是完整后端测试集 |
| 当前供应商真实文本流程 | `deepseek-v4-pro-0813`，约 49.8 秒，检查→修订→独立复审共 3 次调用，人工植入错误的 8 页教案返回 `passed`；修正第 3、5、6 页，其他页保留 |
| 用户截图课件的逐页内容检查 | 从只读保存的大纲契约组装检查输入，未写回用户课件。约 35.4 秒、1 次调用，返回 `needs_revision`；准确指出第 7 页预先展示配对答案、没有路线却要求找路、第 8 页三卡共用合影描述 |
| 当前供应商真实配图 | 首批 4 张图只通过版式与配对检查，银色鱼的物种没有确认，已撤下。随后指定小丑鱼 `Amphiprion ocellaris`，另生成写实与卡通各 1 张，核对橙色身体、三条白带、圆扇形尾鳍及海洋环境；重新渲染 2 张样页。不能把这种人工外观检查称为专家鉴定或自动科学验收 |
| 旧审核源兼容 | 测试移除旧快照中不存在的新字段，再完成审核和采用；未修改页保留原始保存值 |

真实审核试跑还遇到过无效原文路径、把正确内容报错、重复索要已排除内容的资料，以及修订近义页类型导致拒绝。上面的成功结果是在分别修复这些问题后重新运行取得，没有将失败状态改写为通过，也没有增加隐式模型重试。

配图样页使用人工设定的验收稿验证图片与模板传递，不是“输入主题即可自动产出整节优质课”的证明。两次另行真实主题生成中，一份通过硬规则但人工仍发现教学表述问题，另一份因缺少游戏选项、答案映射及揭晓页被正确拦截。不能据单个修订成功样例宣称所有新课件都会合格。

本机可查看的记录位于此次 Codex 工作区 `outputs/teaching-quality-check/`：

- `review-result.json`：真实供应商修订全记录及用量；
- `actual-deck-review-result.json`：截图课件逐页文本检查结果。原始逐页文字/素材描述保持，课程总目标与主线由现存大纲重建，因此没有作为可直接采用的服务器审核快照；
- `species-check/acceptance-page-1.png`、`species-check/acceptance-page-2.png`：更正物种后的实际项目版式样张；顶层同名预览也已替换；
- `species-check/image-trace.json`：更正后样张的配图记录。顶层旧 `image-trace.json` 仅保留首轮试验记录，其中银色鱼未获科学内容验收。

物种纠正参考：[加州科学院麦穗鱼名录（淡水）](https://researcharchive.calacademy.org/research/ichthyology/catalog/fishcatget.asp?genus=Pseudorasbora&species=parva&tbl=species)、[Florida Museum 小丑鱼形态与栖息地](https://www.floridamuseum.ufl.edu/discover-fish/species-profiles/clown-anemonefish/)。不能仅凭原 AI 图断言它就是麦穗鱼；撤下依据是其物种不明确，不能充当合格的海洋认知示例。

## 使用范围

更新并从修复分支启动前后端后，新生成大纲会带上逐页画风和新的教学约束。审核仍须在大纲页显式点击“检查内容 / 检查并修订”，采用修订后再生成 PPT。旧成品和已有错误画面描述不会自动重写；仅点击补图也不会重做教学设计。

当前大纲审核仍不读取实际图片像素、不检查最终导出的全部页面，也不支持对任意手改稿重建原始教案。原有独立视觉检查仍为显式配置开启，没有因这次修改偷偷恢复额外付费重画。不能把“文本审核通过”或“写实画风”展示为“整份 PPT 已科学验收”。本次没有替用户修改现存课件、切换正在运行的主分支或覆盖其未提交的导出功能改动。
