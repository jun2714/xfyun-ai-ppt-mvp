## 使用路径

1. 更新前后端后，生成一份新的幼教大纲，等待保存完成。
2. 在“内容检查”中选择“检查内容”，或“检查并修订”。页面入口最多修订一轮，实际调用后端配置的模型。
3. 等待区显示已用时间。取消或短暂断线后，通过“读取最近结果”核对状态；恢复操作只读状态，不自动再次调用模型。
4. 查看问题原文、检查依据和修改建议，点击“查看第 N 页”定位原稿。
5. 展开修订前后对照；点击“采用修订稿”才会更新已保存的大纲，然后继续生成课件。

页面显示未保存提示并提供“保存草稿”。审核不能替代教师判断，内容审核覆盖文稿和配图描述，实际图片、排版、图片裁切与导出需要另外检查。

## 当前功能边界

- 审核来源必须是本次生成时保存的原始要求、实际参考材料、结构化教案与大纲快照。旧项目没有完整快照时会说明原因。
- 手动修改后，大纲与原始教案快照不再一致，当前版本不会把旧稿审核套用到新稿。仍可正常保存和生成；尚未实现对任意手改大纲重新建立结构化来源的审核。
- 已进入幻灯片生成阶段的项目可以查看文本审核，但暂不把修订回写大纲，避免与已生成页面不一致。
- 浏览器等待取消不等于供应商保证停止执行或停止计费。服务端会清理请求并记录结果，异常退出后仍需核对最近状态。
- 每份课件最多保留 3 份完整报告，旧请求保留去重记录；达到 128 个不同请求后拒绝新任务，不通过遗忘请求记录来自动重发模型调用。
- 后端提供的独立审核接口支持最多两轮修订；页面为了方便控制时间，目前最多一轮。审核不会偷偷加入每次正常 PPT 生成。
