# 教育模板扩展规范（v1）

本轮新增 `classroom-game`（游戏探索 · 观察与挑战）与 `training-workshop`（教研工作坊 · 证据与共创）。所有教育模板统一登记在 `engine/api/templates/education_catalog.py`，启动时导入数据库。新包目前为 `candidate`：已做代码验证，不代表已经通过真实课堂和 PowerPoint/WPS 验收。

## 新包接入

1. 在目录登记唯一 ID、课堂/教研受众、领域、年龄段、关键词和互动类型。实现工厂并接入 `build_education_pack`；默认注册、受众识别复用此目录。新增自动推荐评分时将包加入路由候选并测试。
2. 工厂输出经过 `SlideLayouts` 校验的原生可编辑元素。提供独立的配色、构图、图片风格和节奏，不能仅复制旧包换颜色。
3. 当前教学映射协议保留 `classroom_` / `classroom_training_` 前缀；标题 `heading.title`、操作句 `invitation.cue`、场景 `scene.visual`、正文 `point_N.text`、独立图卡 `card_N.text/visual`。不同字段协议需同时扩展映射器和测试。
4. 提供封面、不同内容数量的场景与图卡、宽松长文备选。每页正文仍来自老师确认的大纲；不缩写、不重新总结、不按素材数组顺序猜测图文配对。容量不足必须明确要求拆页或换模板。
5. 添加前端显示名与真实构图的 SVG 缩略图。运行 `scripts/build-education-previews.py --font <CJK字体路径>` 可复现本轮预览，配图仅为原生矢量占位示意。
6. 测试启动注册、受众隔离、自动推荐理由、原文及图文绑定、真实元素位置和字号、长文回退。真实成品验收通过后，才可升级质量标记。

## 互动与图片约束

新包按观察、比较、选择、排序、提问、揭晓、回顾、研讨角色选择构图。每包的 91 个布局 ID 包含不同正文数量和容量备选，不等于 91 种独立构图。独立图卡同样保留活动角色，揭晓页不会被标成比较页。宽松备选使用中性活动标记，避免容量回退改变题意。

互动由教师带领：口头选择、比较、实体卡片排列、小组讨论、翻页揭晓。没有新增网页专用拖拽、自动判分或依赖宏的按钮。`game.options`、`answer_map`、`sequence_order` 原样保留到教学契约，参考答案进入备注，题目页不自动标注答案。修改大纲后不再采用旧契约生成的互动指导。

配图沿用现有无字、主体完整、语义质量检查和缺图补图链路。本轮为新包配置独立图片风格；普通图片使用 contain，封面保留原生标题与无字背景。既有图片及补图任务不会因新增模板而重新生成。

## 发布验收

- 海洋动物：主题保持，观察/选择/揭晓正确对应，题目不泄露答案。
- 动植物：多图卡逐项对应、排序答案与备注一致，不因模板风格添加无关对象。
- 教研工作坊：案例事实、推断、支持策略、验证指标区分清楚，讲稿不是儿童课堂口吻。
- 每套检查完整页数、长文无溢出、无字图片与完整主体、缺图仍可打开、补图不覆盖编辑。
- 在 PowerPoint 和 WPS 中打开导出的 PPTX，人工检查字体、备注、图片位置与编辑行为。

代码回归与 SVG 预览不能替代真实 DMXAPI 成品、导出软件和多人并发验收。新模板不改变当前缺图完成状态、付费重试策略与单进程队列边界。
