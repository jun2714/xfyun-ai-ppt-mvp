# 教学封面：主题背景与可编辑标题

适用于 kindergarten-classroom、teacher-training，以及 classroom-nature、classroom-story、training-case、training-action 四个变体。

## 生成效果

封面使用一张 1280×720 的主题背景，主要人物、教具和场景集中在左侧。右侧叠加原生不透明白色面板，主题、简短目标和使用类型均为可编辑文字。封面标题默认 64px，长标题沿用现有容量检查与排版，不低于 32px；放不下时提示调整，不截断文字。四个变体沿用各自插画配色，正文版式继续保留。

AI 仅根据当前主题生成无字背景，不接收培训目标全文或教师讲稿作为绘制内容；英语课程的封面同样禁止画入文字。背景请求保持模板指定的风格，不被后续默认配色覆盖。图片模型仍可能不遵循指令，提示词约束不构成图内绝无伪文字的保证，真实图片需要验收。

新大纲的封面采用用户主题原文，不在逗号处切断。首条目标不超过 30 字时完整展示；较长时采用简短导语，所有完整目标与原有封面讲稿保留在教师备注，备注容量扩大至 12000 字。超长主题或备注明确提示调整。已确认大纲中的文字仍按原文映射；重新生成大纲后才应用新的目标整理方式。

## 生图与失败处理

封面新增一个必需背景图片位置，走现有 DMXAPI 图片队列和超时处理；每套课件因此比旧封面多生成一张背景。已完成的背景再次打开时不重复生成。背景失败时原生标题、面板和其他页面保留，缺图不能通过完整成品检查。AI 生图被明确关闭的模式仍沿用原有行为。

成品结构检查允许受不透明原生面板保护的背景与标题重叠，验证图层顺序和面板是否完整覆盖标题；缺失、透明或顺序错误的面板不能豁免遮挡检查。该检查不代替真实编辑器截图及导出文件验收。

## 测试与使用

测试覆盖六套模板的真实 schema → 内容映射 → UI → 背景请求，确认修改后的主题生效、标题不混进图片正文、教师备注完整、英语选项不允许封面绘字，以及成品重开不重复生图。全量 API 回归、独立图片审计测试另行运行，不消耗 DMX 额度。

部署此分支后，启动时会更新内置模板数据库记录；用新课件测试新封面。已有课件的已保存 UI 不自动重排。实际 DMX 图片、多人高峰及 PPTX 导出效果仍需实机验证。多教师并发配置与边界见 [dmx-concurrency.md](dmx-concurrency.md)。
